# Contributing

Thanks for looking. MrSmart is **public to read, not free to use**. See
[LICENSE](LICENSE). Suggestions and fixes are welcome.

## How

1. Open an issue first for anything bigger than a typo.
2. Fork, branch, change. Follow [AGENTS.md](AGENTS.md).
3. Run `dart format lib test && flutter analyze && flutter test`.
4. Open a pull request with what changed and how you checked it.

## By contributing you agree

Your contribution is licensed to the project owner under section 3 of
[LICENSE](LICENSE): the owner may use, change and relicense it, and you get
no ownership or payment. Only submit work you have the right to give.

## Never include

Real access tokens, passwords, API keys, private IP addresses or hostnames
of real networks, emails, phone numbers, personal names, or screenshots
showing any of these. Use placeholders such as `http://homeassistant.local:8123`
and `test-token`.
